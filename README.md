# Flask URL Shortener (SQLite)

## Features
- Create short links (random or custom code)
- Expiry date (in days)
- Click counting / analytics
- Copy-to-clipboard button
- Stats page and JSON API

## Requirements
- Python 3.9+
- See `requirements.txt`
